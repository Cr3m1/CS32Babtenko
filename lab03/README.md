* Лямбда-функція — це коротка функція без окремого імені `def`. Вона приймає аргументи і одразу повертає один вираз. У прикладі `this_is_lambda` отримує ім'я і число та збирає з них рядок. Звичайна функція `a_b_func` лише повертає два значення, а зірочка `*` передає їх у лямбду як два окремі аргументи.

* Відповідь AI на запит «опиши основи Python для вивчення в Jupyter Notebook». У Notebook код ділять на комірки. Комірку запускають окремо, результат з'являється під нею. Змінна, список, цикл і розгалуження виглядають так:

```python
language = "Python"
print(language, type(language).__name__)

numbers = [2, 4, 6]
total = 0
for number in numbers:
    total += number
print("сума:", total)

mark = 8
if mark >= 6:
    print("тема зарахована")
else:
    print("тему треба повторити")
```

Ці три приклади виконано і в [`basics.py`](basics.py), і в [`basics.ipynb`](basics.ipynb). Результат: `Python str`, `сума: 12`, `тема зарахована`.
