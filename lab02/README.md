### Виконання роботи

* Результати виконання завдання:
    1. Створили папку `lab02` у репозиторії та заповнили цей звіт за шаблоном викладача.
    1. У VS Code встановлено розширення Python і Jupyter. Підсвічування коду Python працює через Pylance.
    1. Написали першу програму [`my_first_app.py`](my_first_app.py). У змінну `name` записано ім'я Demid, у змінну `location` — місто Lviv.
    1. Програма вивела рядок із ім'ям, поточними датою і часом та назвою міста.
    1. Той самий код виконано у файлі [`my_first_app.ipynb`](my_first_app.ipynb). Друга комірка має тип Markdown і містить заголовок «Моя перша програма».
    1. Запитали в AI, яку першу програму він написав би. Програму додано нижче і перевірено запуском.

* Код першої програми:

```python
from datetime import datetime

name = "Demid"
location = "Lviv"

print(f"{name} start programming at {datetime.now()}. {location} is the best city!")
```

* Результат запуску `my_first_app.py`:

```text
Demid start programming at 2026-11-18 11:51:33.220658. Lviv is the best city!
```

* Результат виконання комірки в Notebook збігається з цим рядком. Опис коду оформлено заголовком у комірці Markdown.

* Програма, яку запропонував AI, лежить у файлі [`ai_first_program.py`](ai_first_program.py).

AI пояснив її так. Змінна `name` зберігає ім'я, змінна `lessons` зберігає номер лабораторної. Функція `print` виводить текст на екран. Знак `+` з'єднує частини рядка. Останній виклик `print` виводить підпис і число окремо.

```python
name = "Demid"
lessons = 2

print("Hello, " + name + "!")
print("This program remembers a name and a number.")
print("Laboratory number:", lessons)
```

* Результат запуску програми від AI:

```text
Hello, Demid!
This program remembers a name and a number.
Laboratory number: 2
```
