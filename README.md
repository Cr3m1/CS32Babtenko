## 🛠️ Як працювати з репозиторієм і Visual Studio Code

1. Відкрийте папку репозиторію: **File → Open Folder**.
2. Файли `*.md` редагуються як звичайний текст. Попередній перегляд: `Ctrl+Shift+V`. Перегляд поруч із текстом: `Ctrl+K`, потім `V`.
3. Увімкніть автозбереження: лівий нижній кут, **Manage → Settings → Auto Save**.
4. Зміни відправляються на GitHub через ліву панель **Source Control**:
   - натисніть **+** біля файлу або біля всього списку **Changes**, щоб додати файли;
   - напишіть коротке повідомлення, що саме змінилось;
   - натисніть **Commit**, потім **Sync Changes**.
5. Після синхронізації відкрийте репозиторій у браузері і перевірте, що файли з’явились на GitHub.

### Коротко про Markdown

Markdown — це текстовий формат для заголовків, списків, таблиць, посилань і зображень. Його можна писати у Visual Studio Code і одразу дивитися попередній перегляд.

- заголовок: `# Заголовок`
- жирний і курсив: `**жирний**`, `*курсив*`
- посилання: `[текст](адреса)`
- зображення: `![опис](шлях-до-файлу)`
- код: `` `рядок` `` або блок із трьома зворотними лапками

Документація:

- [Короткі відомості про Markdown](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet)
- [Markdown у Visual Studio Code](https://code.visualstudio.com/docs/languages/markdown)
- [Список емодзі](https://gist.github.com/rxaviers/7360908)
- [Шпаргалка команд Git](https://training.github.com/downloads/ua/github-git-cheat-sheet/)

Окремий приклад форматування лежить у теці [`init`](init/README.md).
