## 2. Виділення тексту

Звичайне речення можна зробити **жирним**, *курсивом* або ***жирним курсивом***.

Окремі назви файлів зручно писати як код: `README.md`, `banner.svg`.

~~Цей рядок перекреслено~~ — так позначають те, що вже не використовується.

> Цитата: Markdown читається і в звичайному редакторі, і в попередньому перегляді Visual Studio Code (`Ctrl+Shift+V`).

Емодзі для підписів можна брати зі [списку](https://gist.github.com/rxaviers/7360908). Синтаксис — у [короткій шпаргалці Markdown](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet).
